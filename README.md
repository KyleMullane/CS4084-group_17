Before testing the features of this app, it is important to know the purpose of the app and the intention behind it. It is a travel planner app, with the goal of serving the user as 
an organizational tool. In a sense, it is designed to essentially be a structured notes app that a person can use to plan any trips they might have. It is NOT an app that pulls on real
world data to help the user plan their trip; i.e., it doesn't know of any real locations or legitimate data from a map. This is important because we intentionally chose NOT to restrict 
what the user can put in for destination, departure, transportation, accommodation, activities, etc. A person can use this app however they like -- they could use it to help them plan a trip
to their local grocery store. The only fields that we chose to restrict were dates and budget/prices, because we felt the app could help the user organize when their trips are, and how to
budget their trips. Again, a person could use this app however they like, but specifically for those take the 'happy path' -- the path we would expect a user to take -- and simply employ the 
app as a planner to help them keep track of when their trips are, the budgeting for them, and thetransportation/accommodation/activities within their trips, we felt it could be a helpful tool.
We hope you think the same!
